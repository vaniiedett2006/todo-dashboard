# Desk — Task Dashboard

A simple, clean task management dashboard built with Ruby. Add, complete, and organize your daily tasks in a distraction-free planner-style interface.

**Live demo:** [todo-dashboard-byvani.onrender.com](https://todo-dashboard-byvani.onrender.com)

## Features

- Add new tasks instantly
- Mark tasks as done with a satisfying "stamp" animation
- Delete individual tasks
- Clear all tasks at once
- Live task counter (total, open, done)
- Clean, planner-inspired design

## Built With

- **Ruby** — backend server (using WEBrick, no external frameworks)
- **HTML/CSS/JavaScript** — frontend dashboard
- **JSON** — simple file-based data storage

## Why I Built This

As a Computer Engineering student and aspiring Virtual Assistant, I wanted a hands-on project to practice backend logic, API design, and frontend interfaces — while creating something genuinely useful for task and time management.
